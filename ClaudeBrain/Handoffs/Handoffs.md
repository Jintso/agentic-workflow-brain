## How to Create a Handoff

At the end of every session, run `/wrap-up`. This creates `handoff-NNN.md` using [[Handoff-Template]].

## How to Use a Handoff

At the start of every session:
1. Read [[BRAIN-INDEX]]
2. Read the latest handoff in this folder
3. Then proceed — you have full context

## Why This Matters

Claude Code does not retain memory between conversations. Handoffs are the mechanism that makes it act like it does.
