# Vision

## What AddonManager Aims to Be

A **native, no-fuss Linux GUI** for managing World of Warcraft addons — covering all game versions — so that Linux WoW players never have to manually download, extract, and copy zip files again.

## The Problem It Solves

Linux WoW players have no first-party addon manager. Options are:
- Manual download + extraction (tedious, error-prone)
- Running Windows tools under Wine (fragile, heavy)
- Third-party scripts (no GUI, limited update support)

AddonManager fills this gap with a clean, native GTK4/libadwaita application that feels at home on the Linux desktop.

## Milestone 1

> Download an addon from a GitHub link (for the correct WoW version) and check for updates.

## Long-Term Possibilities

- Support additional addon sources (CurseForge, Wago, direct zip URLs)
- Profiles per WoW character or spec
- Open-source release for the Linux WoW community
- Flatpak packaging for easy distribution
