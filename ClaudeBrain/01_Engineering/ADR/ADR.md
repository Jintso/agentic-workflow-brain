# Architecture Decision Records

ADRs document significant technical decisions — what was decided, why, and what alternatives were considered.

## How to Create an ADR

1. Copy [[ADR-Template]]
2. Name it `ADR-001-[short-topic].md` (increment number)
3. Fill in context, decision, and consequences
4. Link it from this index

## When to Write an ADR

- Choosing between two viable technical approaches
- Deciding on a library/crate when alternatives exist
- Any decision that would be confusing to a future reader without context
- Decisions driven by constraints (e.g., GTK4 + tokio integration approach)
