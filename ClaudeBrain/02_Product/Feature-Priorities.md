# Feature Priorities

## P0 — Milestone 1 (Must Have)

1. **GitHub URL install** — Paste a GitHub repo URL, pick flavor, install addon
2. **Addon list** — See all installed addons with name, version, flavor
3. **Update checking** — Detect newer GitHub releases for installed addons
4. **One-click update** — Download and install the latest version
5. **WoW path config** — Set install paths per WoW flavor

## P1 — Post-Milestone 1 (High Value)

- **Auto-check on launch** — Non-blocking update check at startup
- **Bulk update all** — Single button to update all outdated addons
- **Remove addon** — Uninstall with confirmation
- **GitHub token config** — Higher API rate limits for power users

## P2 — Future (Nice to Have)

- **CurseForge source** — Install from CurseForge addon IDs
- **Wago source** — Install from Wago
- **Direct zip URL** — Install from any zip URL
- **Addon profiles** — Different addon sets per character/spec
- **Flatpak packaging** — Easy install via Flathub

## P3 — Maybe Someday

- **Dependency resolution** — Auto-install addon dependencies
- **Addon search** — Browse/search addons without knowing the URL
- **Backup/restore** — Export and restore addon configurations

See [[MVP-Scope]] for the Milestone 1 boundary. See [[Vision]] for long-term direction.
