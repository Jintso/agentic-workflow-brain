# MVP Scope — Milestone 1

## In Scope

- [x] Add an addon via GitHub repository URL
- [x] Select target WoW flavor (Retail, Classic Era, Cataclysm, etc.)
- [x] Download and install the correct release asset for that flavor
- [x] Display installed addons in a list
- [x] Check for updates against the latest GitHub release
- [x] Update an addon to the latest version
- [x] Configure WoW installation path(s)

## Out of Scope for Milestone 1

- CurseForge / Wago / other addon sources
- Automatic update on launch (nice-to-have, not required)
- Addon profiles or character-specific lists
- Dependency resolution between addons
- Flatpak packaging / distribution
- Multi-user support

## Definition of Done

> An installed addon can be downloaded from a GitHub URL with the correct WoW flavor selected, and the app can detect and surface when a newer release is available.

See [[Execution-Plan]] for the implementation roadmap.
